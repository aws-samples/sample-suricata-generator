# Suricata Rule Generator - Python Requirements
#
# Core application uses only Python standard library modules:
# - tkinter (usually included with Python)
# - re, os, json, ipaddress, typing, urllib
#
# Optional dependencies for enhanced features:

# Advanced Editor with Code Folding (optional)
# Required for Tools > Advanced Editor (Ctrl+E) to use wxPython/Scintilla-based editor
# If not installed, Advanced Editor will prompt user with installation instructions
# The main application works fine without this - only needed for Advanced Editor
wxPython>=4.2.0

# Installation:
# pip install -r requirements.txt
#
# Or install wxPython separately:
# pip install wxPython
#
# Note: wxPython is only required if you want to use the Advanced Editor feature.
# The main tkinter-based application works without it.

# AWS Integration (optional)
# Required for AWS features:
# - Tools > Analyze Rule Usage (CloudWatch Logs analysis)
# - File > Import Rule Group (from AWS Network Firewall)
# - File > Export Rule Group (to AWS Network Firewall)
# - Tools > Traffic Analysis & VPC Endpoints
# - Tools > AI Rule Assistant (Amazon Bedrock-powered rule generation)
# - Tools > Manage Container Associations (AWS Network Firewall container associations)
#
# Minimum bumped to 1.40.62 for the Container Association Manager: the AWS
# Network Firewall container-association APIs (list/create/update/delete/
# describe_container_association) were added in botocore 1.43.62, which pairs
# with boto3 1.40.62. Older boto3 can still run the other AWS features, and the
# Container Association Manager shows an "update boto3" message rather than
# failing, but the manager needs this minimum to function.
boto3>=1.40.62

# Traffic Analysis & VPC Endpoints (optional)
# Required for Tools > Traffic Analysis & VPC Endpoints feature
# Provides fast IP-to-service mapping and AWS IP range analysis
intervaltree>=3.1.0
requests>=2.28.0

# Property-Based Testing (development)
# Required for running property-based tests with Hypothesis
hypothesis>=6.82.0

# XML Security (recommended)
# Protects against XML External Entity (XXE) attacks when importing
# Palo Alto firewall configuration exports
defusedxml>=0.7.1

# Installation for AWS features:
# pip install boto3 intervaltree requests
#
# Note: AWS features are optional. The core application works without them.
# You'll be prompted to install these packages when accessing AWS features.
